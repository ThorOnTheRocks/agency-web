# Portfolio Redesign

Astro-based portfolio site for positioning Gianluca Galota as a premium solo specialist for launch, redesign, and rescue work.

## Stack

- Astro
- React islands
- Tailwind CSS
- Framer Motion
- Astro Content Collections

## Commands

```sh
pnpm install
pnpm dev
pnpm build
pnpm preview
pnpm astro check
```

## Content structure

- `src/content/projects`: featured client proof, supporting commercial work, and hidden archive material
- `src/data/homepage.ts`: shared positioning copy for services, trust, fit, and process
- `src/config/site.ts`: sitewide navigation, CTA, and positioning configuration
